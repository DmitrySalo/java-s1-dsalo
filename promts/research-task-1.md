# Задание на исследование 1

Перед тобой проект "Ароматека". Проект задумывался как персональная картотека парфюмов. Проект находится на этапе разработки. Проект разрабатывался на принципах clean architecture Боба Мартина и domain driven design. На данном этапе разработки, проект представляет из себя модульный монолит. На текущий момент, содержимое файлов README.md может быть неполным или недостоверным.

Твои задачи:
1. Досконально изучи проект.
2. Создай в корне проекта файл ARCHITECTURE.md.
3. В ARCHITECTURE.md зафиксируй:
   - Назначение проекта
   - Принципы проектирования проекта
   - Архитектурные паттерны, которых придерживались разработчики
   - Детальную структуру проекта
   - Назначение модулей и пакетов
   - Детальный список технологий и их версий, используемых на проекте
   - Назначение используемых технологий и библиотек
4. Актуализируй файлы README.md.
5. Любую иную актуальную и полезную для разработчиков и архитекторов информацию.
6. Создай в корней проекта директорию promts.
7. Создай в директории promts файл в под названием research-task-1.md.
8. Зафиксируй в research-task-1.md текст задания, по которому ты выполняешь работу.
9. Создай в корне проекта файл REPORT.md - это журнал ведения работ над проектом.
10. Зафиксируй в REPORT.md краткое описание задания, по которому ты выполнил работу, с указанием текущей даты и ссылки на промт задания research-task-1.md.
11. Изменения в документации добавь в git.
