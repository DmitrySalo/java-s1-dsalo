# Задание: обязательное документирование заданий и журнала работ

1. Вести `REPORT.md` в хронологическом порядке сверху вниз: новые записи добавлять в конец файла.
2. Для каждого полученного задания обязательно создавать отдельный Markdown-файл в директории `promts` с текстом задания.
3. Каждая запись в `REPORT.md` должна ссылаться на соответствующий файл задания из `promts`.
4. Дополнить существующие инструкции для агентов этим обязательным процессом.
