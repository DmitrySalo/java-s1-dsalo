# Примеры запросов

- Получение: `Получи парфюм с UUID 123e4567-e89b-42d3-a456-426614174000`.
- Создание: `Создай Example, рейтинг 8, описание Example description, EAU_DE_PARFUM, WOODY, UNISEX, WINTER, STRONG, MODERATE, AVAILABLE`.
- Обновление: `Обнови UUID ..., используя полный набор характеристик`.
- Подтверждение: повторите исходный HTTP-запрос с `{"message":"<исходный запрос>","confirmed":true,"prepared_operation_id":"<ID из первого ответа>"}`; ID одноразовый и действует пять минут.
- Отмена: не передавайте `confirmed: true`; операция вернёт `confirmation_required` без HTTP-мутации.
- Ошибка: неполный или неоднозначный набор характеристик возвращает безопасную ошибку без tool-вызова.
